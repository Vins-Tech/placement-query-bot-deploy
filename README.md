# 🚀 BNMIT Placement Chatbot (Streamlit Deployment)

This repository hosts the **Streamlit web application** version of the BNMIT Placement Chatbot —  
an AI-powered bot that answers placement-related questions using the logic from the core repository.

---

### 🌐 Live Demo
🟢 Try it here:  
[app](https://placement-query-bot-deploy-mhzuaomjatq3jiryatemjp.streamlit.app/)

---

### 🧩 Related Repository
For the backend logic and semantic routing engine, see:  
👉 [placement-query-bot (Core Repo)](https://github.com/VinsTechn/placement-query-bot)

---

### 🧠 Features
- Groq LLaMA-powered responses  
- Daily shared query limits (via JSONBin API)  
- Auto reset every midnight  
- Responsive Streamlit interface with sidebar info  
- Independent queries (non-persistent chat)
